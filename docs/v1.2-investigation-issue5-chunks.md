## 3. 风险提示
1. Onboarding 懒化：新用户首启先看到 Suspense fallback 再进 onboarding（数百毫秒级）；fallback 必须保留。
2. 弹窗类动态化：首开多一次 chunk 加载延迟，低频路径，先例在产（HtmlArtifactPopupContext.tsx:29 / exportBackends.ts:723）。
3. KaTeX：数学首帧需等动态组就绪（与现状一致）；保持 contrib（copy-tex→mhchem）先于 rehype-katex 注册顺序（Markdown.tsx:59-64）。
4. CodeMirror 链：CodeEditor 懒化对默认渲染无影响（默认走 CodeViewer/shiki）；CodeStyleProvider 静态边不一起处理则拆不干净。
5. lodash-es 迁移：63 文件一次性全迁，混用双实例；独立提交并跑全量 gate。
6. i18n 懒 locale：语言切换异步，key 文件不动。
7. 验证：每步 `node tools/measure-eager.cjs --json` 复测；不加 manualChunks、不动 build config。

优先落地顺序：#2 ErrorDetailModal（单点零歧义 409KB）→ #1 onboarding 链（830KB）→ #3 CodeMirror 链（750KB 含 CodeStyleProvider 边）→ #7 ObsidianExportPopup / #6 franc / #8 htmlparser（小而零险）→ #5 lodash / #4 i18n（面大，单独排期）。
